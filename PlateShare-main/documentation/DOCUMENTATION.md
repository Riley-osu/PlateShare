# PlateShare Documentation

## Project Overview

PlateShare is a mobile application designed to reduce food waste on college campuses by connecting organizations with students who can claim leftover food.

Organizations can create listings for available food, including information such as the food description, pickup location, pickup window, and dietary information.

Students can browse available listings and reserve food for pickup.
